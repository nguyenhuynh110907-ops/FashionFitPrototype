# Công cụ dữ liệu và huấn luyện

Các BAT trong thư mục này tự chuyển thư mục làm việc về gốc project trước khi chạy Python. Không cần chép chúng trở lại gốc. Công cụ training không dùng để mở game.

Để chơi, dùng `Open_FashionFit_Model.bat` ở gốc hoặc shortcut **01 - VAO GAME VR** trên Desktop.
