# Third-party asset provenance — v0.5

## Temporary female technical body

This is a generic stand-in, not the user's original character and not reconstructed from their photograph.

MakeHuman core graphical data, explicitly released under CC0 in September 2020:

- Repository: https://github.com/makehumancommunity/makehuman
- Commit: `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`
- `makehuman/data/3dobjs/base.obj`
- `makehuman/data/targets/macrodetails/caucasian-female-young.target`
- Full license: `Tools/SourceAssets/LICENSE.ASSETS.md`
- Asset declarations and original copyright notices remain at the top of each source file.
- Official asset-license explanation: https://static.makehumancommunity.org/about/license.html

The data was transformed into a 1.72 m neutral material mannequin, helper geometry removed, arms lowered, a simplified rig/weights generated and the surface subdivided. No MakeHuman application code, scripts, executables, third-party textures or shaders were imported. Source hashes are recorded in Verification/Female_Data_Check.json.

## User input

Reference/Female_Body_Reference.png is the supplied reference image. It is retained unchanged. It is not a rigged 3D asset. The older dress source image is retained in Reference/Dress_Source.png for context, not used as the new default garment.

## Original project content

Room geometry, sample skirt, fitting code, experimental solver and shaders are authored for this prototype. Numerical test math compatibility code is test-only, outside Assets.

Unity and XR packages are resolved by Unity's Package Manager under their respective licenses. Reference DLLs, compilers, downloaded tooling and Python dependencies used outside Unity for validation/rendering are not distributed in the project.

The Ronaldo asset and legacy procedural dress are absent from this version's active resources. The previous checkpoint remains in project version history.


## Adult male/female pose mannequins

Additional CC0 MakeHuman adult male/female geometry is documented in Verification/PoseStudio/SOURCES.json. The derived generic 17-bone rig, distance-based skin weights and Grip/IK pose controls are authored for this project. No MakeHuman AGPL program code was imported. Raw core data and LICENSE.ASSETS.md remain in Tools/SourceAssets.
